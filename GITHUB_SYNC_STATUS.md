GitHub auto-push: implemented for newly saved Code Studio snippets. OAuth uses PKCE, one-time state and encrypted tokens. The user must authorize public_repo, configure an initialized public repository, then enable auto-push. Only that repository's default branch is used. Each saved record has a unique remote path. Failed pushes can be retried under Settings; files with different content are never overwritten. GitHub Client ID and Client Secret remain required before live testing. Register callback http://localhost:5173/api/github/callback. No external-platform submission sync exists. A process interruption during pushing may leave a job in pushing status; no automatic recovery is implemented yet.
